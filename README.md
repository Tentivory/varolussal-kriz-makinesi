# 🤔 Varoluşsal Kriz Makinesi

> **UYARI:** Bu yazılım hayatınızı değiştirebilir. Veya değiştirmeyebilir. Garanti verilmez.

## Nedir Bu Şey?

**Varoluşsal Kriz Makinesi**, modern insanın en temel ihtiyacı olan "neden buradayım?" sorusunu cevaplamak üzere tasarlanmış, dünyanın en gelişmiş (ve en işe yaramaz) yazılımıdır.

Gerçekten çalışır. Gerçekten bekletir. Gerçekten krize sokar. Sonra da "işte bu kadar" der.

## Özellikler

- ✅ Rastgele varoluşsal kriz üretir
- ✅ Derin düşünme animasyonu (noktalarla)
- ✅ Hiçbir şey çözmez
- ✅ Ctrl+C ile kaçabilirsiniz (ama kriz kalır)
- ✅ Tamamen Türkçe ve abartılı
- ✅ Patates içermez (söz verdik)

## Kurulum

```bash
git clone https://github.com/Tentivory/varolussal-kriz-makinesi.git
cd varolussal-kriz-makinesi
python3 kriz_makinesi.py
```

Python 3 yeter. Başka hiçbir şeye ihtiyacınız yok. İhtiyacınız olan tek şey biraz sabır ve varoluşsal boşluk.

## Nasıl Çalışır?

1. Programı çalıştırırsınız.
2. Biraz bekler.
3. Size bir kriz fırlatır.
4. Analiz eder (yine bekler).
5. Anlamsız bir sonuç verir.
6. Siz kalırsınız.
